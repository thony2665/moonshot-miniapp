# Moonshot FXFX.AI Telegram Mini App (Demo Mockup) 这是根据用户上传的屏幕录制影片，高保真还原的 Telegram Mini App 前端演示版本。 ## 功能特点 - 完全暗色主题，橙色强调色，匹配原版 UI 风格 - 6 个阶段导航：观察 / 解释 / 结构 / 推演 / 审核 / 触发 - 包含价格面板、市场联动、多个 AI Agent 卡片、关键位、情景推演、风险设置、历史信号、Paper Trading 等 - 集成 Telegram WebApp SDK，可直接作为 Mini App 使用 - 浮动「真人客服」按钮 ## 如何部署为真正的 Telegram Mini App 1. **托管文件** - 将 `moonshot-fxfx-miniapp.html` 重命名为 `index.html` - 上传到任意支持 HTTPS 的静态托管（推荐）： - GitHub Pages - Vercel / Netlify - Cloudflare Pages - 自己的服务器 2. **创建 Telegram Bot** - 打开 [@BotFather](https://t.me/BotFather) - 发送 `/newbot` 创建机器人 - 发送 `/newapp` 创建 Mini App - 设置 Mini App 的 URL 为你托管的 `index.html` 地址（必须是 HTTPS） 3. **测试** - 在 BotFather 中获取 Mini App 链接（格式：`https://t.me/yourbot/app`） - 在 Telegram 中打开即可看到效果 ## 注意事项 - 这是**前端演示版本**，所有数据为影片中的静态快照，不包含实时行情、真实 AI 推理后端或交易执行。 - 原版系统涉及复杂的多 Agent 工作流、新闻抓取、路径模拟等，需要独立后端支持。 - 如需完整功能复刻，需要另外开发数据源对接、Agent 逻辑、Telegram Bot 后端等。 ## 文件 - `moonshot-fxfx-miniapp.html` — 完整单文件 Mini App 打开此文件即可在浏览器中预览（建议使用手机模式或直接在 Telegram 中打开）。
